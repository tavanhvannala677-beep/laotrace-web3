# นโยบายความปลอดภัยของระบบ (Security Policy & Best Practices)

เอกสารระบุแนวทางการรักษาความปลอดภัยสำหรับ **LaoTrace Web3**

---

## 🔒 1. การรักษาความปลอดภัยของ Private Key และ Wallet

- **ห้ามเก็บ Private Key หรือ Seed Phrase ลงในโค้ดหรือ Git Repository โดยเด็ดขาด**
- โค้ดฝั่งหน้าบ้าน (Frontend) ติดต่อกับกระเป๋าผ่าน Browser Extension (เช่น MetaMask / Injected Provider) หรือผ่าน RPC สาธารณะสำหรับการอ่านข้อมูลแบบ Read-Only

---

## 🛡️ 2. กลไกการตรวจสอบสิทธิ์ตามสถาปัตยกรรม Chain of Custody

1. **สิทธิ์การบันทึกต้นน้ำ:**
   - ผู้สร้างล็อตสินค้า (`creator`) จะถูกบันทึกที่อยู่กระเป๋าไว้บน Smart Contract อย่างถาวร
2. **สิทธิ์การอัปเดตกลางน้ำ:**
   - ระบบหน้าบ้านมีตารางผูกสิทธิ์ (`custodyMap`) ตรวจสอบว่ากระเป๋าที่เชื่อมต่อมีสิทธิ์สำหรับล็อตสินค้านั้นจริงก่อนอนุญาตให้กดส่งธุรกรรม
3. **การอ่านข้อมูลปลายน้ำ:**
   - ผู้บริโภคสามารถอ่านข้อมูลผ่านฟังก์ชัน `view` (`getTimeline`, `getProductDetails`) ได้อย่างปลอดภัยโดยไม่ต้องอนุญาตสิทธิ์การเข้าถึงกระเป๋า

---

## 📢 3. การรายงานช่องโหว่ความปลอดภัย

หากพบช่องโหว่หรือข้อผิดพลาดด้านความปลอดภัย สามารถรายงานได้โดยตรงผ่าน GitHub Issues หรือส่งอีเมลถึงทีมผู้พัฒนา
