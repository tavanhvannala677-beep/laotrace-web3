# คู่มือการทดสอบระบบครบวงจร (End-to-End Testing Guide)

แนวทางการทดสอบระบบ **LaoTrace Web3** ครบทั้ง 3 เฟส (ต้นน้ำ -> กลางน้ำ -> ปลายน้ำ) เพื่อเตรียมความพร้อมก่อนนำเสนอจริง

---

## 🧪 เฟสที่ 1: ทดสอบฝั่งชาวสวนต้นน้ำ (`/?page=farmer`)

1. เปิดเบราว์เซอร์ไปที่ `http://localhost:5173/?page=farmer`
2. เลือกหมวดหมู่สินค้า เช่น **☕ กาแฟโบลาเวน**
3. กรอกรหัสล็อตสินค้าใหม่ เช่น `1009`
4. อัปโหลดไฟล์รูปภาพผลผลิตหรือใบรับรองคุณภาพ -> สังเกตว่าระบบสร้างรหัส `IPFS CID (bafybei...)` อัตโนมัติ
5. เลือกกระเป๋าผู้รับช่วงต่อ (กลางน้ำ) เช่น **โรงคั่วกาแฟเวียงจันทน์ (`0x3C44...93BC`)**
6. กดปุ่ม **"บันทึกขึ้น Blockchain และสร้าง QR Code"** -> ระบบจะแสดงป้าย QR Code สำหรับติดถุงสินค้า

---

## 🚚 เฟสที่ 2: ทดสอบฝั่งผู้ประกอบการกลางน้ำ (`/?page=midstream`)

1. เปิดไปที่ `http://localhost:5173/?page=midstream`
2. สังเกตว่าระบบจะกรองแสดงเฉพาะล็อตสินค้าที่ถูกระบุส่งมอบให้กระเป๋าที่กำลังเชื่อมต่ออยู่เท่านั้น
3. ลองสลับกระเป๋าเป็นใบอื่นที่ไม่ได้รับมอบหมาย -> ระบบจะซ่อนล็อต `1009` ทันที (ป้องกันการอัปเดตข้ามสิทธิ์)
4. สลับกลับมาที่กระเป๋า **โรงคั่วกาแฟ (`0x3C44...93BC`)** แล้วเลือกขั้นตอน เช่น `"คั่วระดับ Medium Roast & บรรจุถุงสุญญากาศ"`
5. กดปุ่ม **"ยืนยันการอัปเดตลง Blockchain"**

---

## 📱 เฟสที่ 3: ทดสอบฝั่งผู้บริโภคปลายน้ำ (`/?productId=1009`)

1. เปิดไปที่ `http://localhost:5173/?productId=1009` (จำลองการสแกน QR Code ข้างถุงสินค้า)
2. ตรวจสอบว่าหน้าเว็บแสดงผล **Verified by Blockchain** โดยไม่มีปุ่มเชื่อมกระเป๋า Web3 กวนใจผู้บริโภค
3. ตรวจสอบเส้นทาง **Provenance Timeline** ว่าแสดงครบทั้งขั้นตอนต้นน้ำและกลางน้ำ พร้อมป้าย `CID` และลิงก์ไปที่ **LAB Chain Explorer**
4. ทดสอบกดปุ่ม **"ดาวน์โหลดใบรับรอง JSON (EUDR Compliance)"** และ **"ดาวน์โหลดตารางประวัติ CSV (Excel)"**
